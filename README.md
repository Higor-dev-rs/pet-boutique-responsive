Projeto de um site institucional fictício para uma Pet Boutique, desenvolvido com HTML e CSS como parte dos meus estudos em Desenvolvimento Web Frontend.


---

## 📚 Sobre o projeto

Este projeto consiste em um site institucional contendo:

- Header com logo e navegação
- Seção sobre a empresa
- Seção de serviços
- Layout moderno e organizado

O projeto foi desenvolvido com base em um exercício da DevMedia e aprimorado com boas práticas modernas de desenvolvimento frontend.

---

## 📱 Mobile First

Este projeto foi desenvolvido utilizando a abordagem **Mobile First**, onde o layout foi inicialmente construído para dispositivos móveis e depois adaptado para telas maiores usando media queries.

Benefícios dessa abordagem:

- Melhor experiência em dispositivos móveis
- Código mais organizado e escalável
- Prática utilizada no mercado profissional
